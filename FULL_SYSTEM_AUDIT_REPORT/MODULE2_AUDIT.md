## 2. BẰNG CHỨNG KIỂM TRA TRUY VẤN LINQ & PHÂN TRANG SERVER-SIDE

- Trong [DotHienMauRepository.cs](file:///e:/InformationTechnology/visual%20t%C3%ADm/QuanLyHienMau_UNETI2_TI17A5HN/QuanLyHienMau_UNETI2_TI17A5HN/Repositories/DotHienMauRepository.cs#L55-L143):
  - `GetQueryable()` trả về `IQueryable<DotHienMau>` (`_context.DotHienMaus.Include(d => d.DonViToChuc).AsQueryable()`), **không** gọi `.ToList()` sớm trong bộ nhớ.
  - Khi kiểm tra bằng `query.Skip(0).Take(6).ToQueryString()`, EF Core dịch toàn bộ điều kiện tìm kiếm, lọc nhóm máu, lọc hạn đăng ký và sắp xếp sang SQL Server với mệnh đề `ORDER BY ... [d].[MaDot] OFFSET @__p_1 ROWS FETCH NEXT @__p_2 ROWS ONLY`.
  - Xử lý biên số trang an toàn:
    ```csharp
    if (page < 1) page = 1;
    int totalItems = await query.CountAsync();
    int totalPages = (int)Math.Ceiling((double)totalItems / PageSize);
    if (totalPages < 1) totalPages = 1;
    if (page > totalPages) page = totalPages;
    ```
